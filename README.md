# Employee Polls

A React/Redux application where employees can create and vote on "Would You Rather" polls. Users can log in, create polls, vote on existing polls, and view a leaderboard ranked by participation.

## Installation

```bash
npm install
```

## Start the Application

```bash
npm start
```

Then open [http://localhost:5173](http://localhost:5173) in your browser.

## Run Tests

```bash
npm test
```

## Features

- Log in as an existing user
- View unanswered and answered polls on the home page
- Vote on polls and see live results with percentages
- Create new polls at `/add`
- View the leaderboard at `/leaderboard`
- Log out and log back in as any user

## Built With

- React
- Redux Toolkit
- React Router
- Vite
- Jest + React Testing Library
